# Editing a video with their style

Use this whenever they ask you to edit, plan or storyboard a video in a folder that has their STYLE.md.

## Before you touch anything
1. Read STYLE.md in full. "Feedback from edits" (newest first) and "Slop we cut" win over everything else.
2. Check the footage: frame rate, size and length (ffprobe if it's installed). Write the frame rate down.
   If "Lips out of sync" is cut, the final render uses that exact frame rate.
3. If they have a script or notes, read them. Ask for the comment keyword if there's a call to action.

## While you edit
- STYLE.md fixes the look, not what gets made. For every line, ask what would explain THAT idea best, then
  make it inside the locked look. Don't repeat the same layout twice in a row.
- Use the locked captions, titles, key words, zooms, visuals, labels and transitions with their exact
  numbers. If you need something that isn't locked, make it fit the locked look and say so afterwards.
- Real things on screen only: real screenshots, real logos, real photos. If you don't have one, ask.
- Keep text inside the safe zone (clear of the top 8%, bottom 20% and right 12% of a vertical video).
- If "Dead space" is cut, cut every silence longer than 0.12 s. If "A sound on every graphic" is cut, only
  the moments that matter get a sound.
- Show them a plan (a short beat list, or stills) before any long render, so they can change direction early.

## After every edit
- When they give a note ("the logos are too small", "I hate that zoom"), fix it, then add it to STYLE.md
  under "Feedback from edits" as one dated line in their words, plus the rule it means ("Logos at least 40%
  of the frame width"). The next edit reads it first.
- If a note changes something locked, update the Locked section too and say so in one line.
