## How Claude uses this file
1. Read this whole file before planning an edit. "Feedback from edits" and "Slop we cut" win over everything else.
2. This file fixes the look, not what gets made. For every line, ask what would explain that idea best, then make it inside this look. Don't just reuse the same few layouts.
3. Use real things on screen: real screenshots, real logos, real photos. Never stand-ins.
4. Keep text inside the safe zone: clear of the top 8%, the bottom 20% and the right 12% of a vertical video.
5. When I give a note on an edit, fix it, then add it under "Feedback from edits" with the date so the next edit already knows.
